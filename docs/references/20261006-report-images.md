# 刊物配图与摘要展示

用户于 2026-10-06 要求执行日报配图与无图布局修复。生产 10 月 5、6 日头条及同事件文章已有合尺寸图片，但旧选图条件将摘要模式全部排除；1440px 桌面头版的右栏撑高整行，造成左栏大片空白。原始上游代码已有这两处逻辑，官方当前部署配置未核实。

决定沿用来源 config，增加 `reportImages` 布尔键：true 允许刊物借图，false 禁止；未配置时保留全文文章资格，并复用 X 现有媒体展示能力。只影响日报、周报和月报封面，正文与 RSS 全文许可不变。后台所有来源类型接受该键，拒绝非布尔值。选择器只取已公开、满足公开时间及资格条件的头条或同事件文章，保留 480px 尺寸筛选和优先级，并标明实际供图来源。

无图及图片加载失败时，头条按实际内容高度排列，看点与目录位于后续紧凑区域；有图沿用现有头版布局。历史刊物在读取时应用规则，不重写日报内容、不调用模型、不重跑回填。拒绝直接删除全部图片资格条件或开启全文来换取配图；单改布局不能恢复已经采到的 X 图片。

独立 review-decision 七项成立、放行。作用域为刊物封面与布局，非全站媒体权限重构；此时实现、历史样本、图片加载及移动布局尚待验证。不承诺每期都有合适图片。
