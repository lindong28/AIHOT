# 历史回填实现决定（2026-10-01）

部分替代：2026-10-02 的[历史回填启动决定](20261002-backfill-launch.md)替代本文“所有角色仅限 self-hosted、禁止订阅 fallback”及“本轮仅提供手动有界执行”的边界；原文审核、回执和历史隔离要求仍有效。下文保留当时实现与验收快照。

状态：本机实现、模拟模型验收与代码独立审查完成。范围仅为本机代码和模拟模型验收，尚未启动真实历史回填或生产切站。

用户要求历史原文完整、日期连续、逐步处理与发布、可见进度，并保留实时处理。最新修订明确两条链都经个人 llm-gateway；另一个 session 负责个人 Gateway 对接公司 GPU 和三个自部署模型。本项目不改共享 Gateway 政策。

采用独立持久批次与条目、独立执行入口，复用 AIHOT 的原生材料、五角色编辑分析与 publication。拒绝改全局模型配置复用实时队列（互相干扰），拒绝重写编辑算法（形成两套逻辑），拒绝另建历史内容库（无法直接原生发布）。回填模型必须通过 discovery 核实为 self_hosted，并精确固定 route；不允许商业 API fallback。回执仍记录真实 attempt，使用独立 backfill 预算，不把未知费用记为零。

一次性转换器只输出原始字段和完整性审核证据。无完整性证据默认待核实，短帖不因短而排除，长文不因长而合格；多版本冲突须明确选择。日期连续指 UTC 日期每天至少有合格原文，不表示每个来源完整。冻结合格清单后再计算分母，169,100 个候选不是合格数量。

仅新建的原生文章归该批次管理，既有身份不覆盖。受管原文固定 revision/hash，后续实时采集只追加发现记录，不自动改写或重算。普通队列、人工单篇重跑与定时全文/引用翻译不处理受管历史。当前回填范围为预筛、双评分、结构抽取、理解或标题摘要以及发布，不包含独立全文/引用翻译、事件归组或历史日报。

暂停阻止下一次模型调用，在途请求结算后停止；续跑使用已有回执。未知回执必须先核对，不透明重试。后台分别展示已处理、已发布、过滤、失败、待处理、逐日进度与模型配置，不把失败算完成或把暂停当成撤回发布。

尚未验证：部署后的模型 ID、路由、接口兼容和 GPU 容量；最终合格连续区间；真实吞吐与模型效果。归属：模型资源由部署 session 提供，原文审核和项目接入由 AIHOT 迁移工作承接。长期无人值守回填启用前，AIHOT 维护者需接入现有服务监督与故障通知；本轮只提供有界执行命令与持久失败状态，不启动常驻回填服务。

独立决定审查：七项成立。发现的全局翻译绕路和原文更新漂移已纳入上述决定。代码审查发现的未知分析结果被误计完成、模型预检期间可改绑定两项问题，均建立失败测试后修复并通过复审；无未处置基线独立项。

本机验证：后端全套 153 项、Web 11 项通过，typecheck、Web 构建及本机 smoke 完成；回填专项 9 项包含转换器、真实 PostgreSQL 与本机模拟 Gateway。模拟覆盖五个角色、三个模型绑定、两个连续 UTC 日期、并发 1/2、发布/过滤/已有/失败/暂停/缺模型及回执恢复。后台另以桌面与 390px 手机视口实际读取并操作暂停，独立预览库只含合成样例。上述读数不证明真实模型兼容、效果或 GPU 吞吐；原文候选尚未完成逐条审核，也未导入真实历史批次。
