## Token 与费用估算

没有启动新模型调用。以类型 × 月份 × 正文长度档分层，每层按 ID 的 SHA-256 排序取最多 4 条，以层大小加权。n=1,064 条不同材料、386 层、65 个不同 source ID（总体 189）；类型为 Feed 695、Web 150、微信 139、X 80。使用本仓真实预筛/评分/理解/摘要 prompt builder，并按同一模板构造结构 prompt；来源字段为估算映射，X 输入用存储文本，未完整重建所有引用/图片字段。它是离线容量估算，不是采集或模型质量评测。

Token 使用 `o200k_base` 代理 tokenizer，不是三家原生 tokenizer。校准复用了本机 2 篇不同来源文章的既有回执；8 次预筛/结构/评分请求重建出的 system/user hash 均匹配，原生输入 token 与代理比值：预筛 0.993–1.008、结构 0.990–1.000、评分 0.934–0.966。两次理解请求 user hash 不匹配，未用于输入校准；它们也不能证明视觉输入成本已覆盖。没有把两篇样本外推为所有语言、长文或视觉的误差保证。

全体候选每条的加权平均输入 token 代理值：预筛 774、每次评分 2,908、结构 1,074、理解 4,470、摘要 3,015。预筛输出假设 24、结构 150、理解 400、摘要 200；评分输出包含 reasoning，既有 4 次真实评分分别为 870、344、886、361 token，中间情景取约 620。所有情景按缓存未命中计费，不使用旧 RADAR 通过率或标签预测新筛选结果。真实摘要分支会对部分中文短帖及极短文本免调用；本估算对到达该分支的材料统一计一次，因此这一项可能偏高。
